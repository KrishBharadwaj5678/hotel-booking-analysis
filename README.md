## <img src="https://github.com/KrishBharadwaj5678/hotel-booking-analysis/raw/main/assets/readme/features.gif" width="35"/> Features

|   Feature                  |  Description                                                                                                                      |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 🔄 **Data Transformation**  | Organized and structured the dataset for accurate and efficient analysis.                                                           |
| 📊 **Pivot Tables**         | Built Pivot Tables to summarize and analyze hotel booking data from multiple perspectives.                                          |
| 🎛️ **Interactive Slicers** | Added slicers to enable quick and interactive data filtering.                                                                       |
| 📉 **Data Visualization**   | Presented insights through charts and visual reports for better understanding.                                                      |
| 📅 **Trend Analysis**       | Analyzed booking patterns, cancellations, and customer behavior.                                                   |
| 💡 **Business Insights**    | Derived actionable insights to support data-driven decision-making.                                                                 |
| 🧮 **Excel Functions**      | Leveraged Excel formulas and built-in features for analysis and reporting.                                                          |
