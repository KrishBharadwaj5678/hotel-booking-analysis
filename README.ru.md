<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/hotel-booking-analysis/raw/main/assets/readme/hotel.webp" width="40"/> Анализ бронирований отелей </h1>

<p align="center">
  Этот проект демонстрирует полный процесс аналитики данных в Excel: преобразование необработанных данных о бронированиях отелей в структурированные выводы с помощью очистки данных, анализа и интерактивных отчётов.

## <img src="https://github.com/KrishBharadwaj5678/hotel-booking-analysis/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
|------------|----------|
| 🔄 **Преобразование данных** | Организация и структурирование набора данных для точного и эффективного анализа. |
| 📊 **Сводные таблицы** | Создание сводных таблиц для анализа данных о бронированиях отелей с разных точек зрения. |
| 🎛️ **Интерактивные срезы** | Добавление срезов для быстрого и удобного фильтрования данных. |
| 📉 **Визуализация данных** | Представление результатов с помощью диаграмм и визуальных отчётов для лучшего понимания. |
| 📅 **Анализ тенденций** | Анализ моделей бронирования, отмен и поведения клиентов. |
| 💡 **Бизнес-инсайты** | Получение практических выводов для поддержки принятия решений на основе данных. |
| 🧮 **Функции Excel** | Использование формул Excel и встроенных инструментов для анализа и создания отчётов. |

## <img src="https://github.com/KrishBharadwaj5678/hotel-booking-analysis/blob/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/hotel-booking-analysis.git
````

### 2️⃣ Переход в папку проекта

```bash
cd hotel-booking-analysis
```

### 3️⃣ Откройте файл `HotelBooking.xlsx` с помощью **Microsoft Excel 2016 или более поздней версии**.
