<p align="center">
  このプロジェクトでは、Excelを使用したエンドツーエンドのデータ分析プロセスを紹介します。ホテル予約データを整理・分析し、インタラクティブなレポートを通じて実用的なインサイトへ変換します。

## <img src="https://github.com/KrishBharadwaj5678/hotel-booking-analysis/raw/main/assets/readme/features.gif" width="35"/> 主な機能

| 機能 | 説明 |
|------------|------------|
| 🔄 **データ変換** | 正確で効率的な分析を行うために、データセットを整理・構造化しました。 |
| 📊 **ピボットテーブル** | ホテル予約データをさまざまな視点から集計・分析するためのピボットテーブルを作成しました。 |
| 🎛️ **インタラクティブスライサー** | データを素早く簡単にフィルタリングできるスライサーを追加しました。 |
| 📉 **データ可視化** | グラフやビジュアルレポートを使用して、分析結果を分かりやすく表示しました。 |
| 📅 **トレンド分析** | 予約パターン、キャンセル傾向、顧客行動を分析しました。 |
| 💡 **ビジネスインサイト** | データに基づいた意思決定を支援する実用的な洞察を導き出しました。 |
| 🧮 **Excel関数** | Excelの数式や標準機能を活用して分析とレポート作成を行いました。 |

## <img src="https://github.com/KrishBharadwaj5678/hotel-booking-analysis/blob/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローンする

```bash
git clone https://github.com/KrishBharadwaj5678/hotel-booking-analysis.git
````

### 2️⃣ プロジェクトフォルダへ移動する

```bash
cd hotel-booking-analysis
```

### 3️⃣ `HotelBooking.xlsx` ファイルを **Microsoft Excel 2016以降** で開いてください。
