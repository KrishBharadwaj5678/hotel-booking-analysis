<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/hotel-booking-analysis/raw/main/assets/readme/hotel.webp" width="40"/> Análise de Reservas de Hotéis </h1>

<p align="center">
  Este projeto demonstra um processo completo de análise de dados no Excel, transformando dados brutos de reservas de hotéis em informações estruturadas através de limpeza, análise e relatórios interativos.

## <img src="https://github.com/KrishBharadwaj5678/hotel-booking-analysis/raw/main/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
|------------|------------|
| 🔄 **Transformação de Dados** | Organização e estruturação do conjunto de dados para uma análise precisa e eficiente. |
| 📊 **Tabelas Dinâmicas** | Criação de tabelas dinâmicas para resumir e analisar dados de reservas de hotéis sob diferentes perspectivas. |
| 🎛️ **Segmentações Interativas** | Adição de segmentações para permitir uma filtragem rápida e interativa dos dados. |
| 📉 **Visualização de Dados** | Apresentação de informações através de gráficos e relatórios visuais para melhor compreensão. |
| 📅 **Análise de Tendências** | Análise de padrões de reservas, cancelamentos e comportamento dos clientes. |
| 💡 **Insights de Negócio** | Extração de informações úteis para apoiar decisões baseadas em dados. |
| 🧮 **Funções do Excel** | Utilização de fórmulas e recursos integrados do Excel para análise e criação de relatórios. |
